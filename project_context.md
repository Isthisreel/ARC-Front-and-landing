# Contexte du Projet : IoE Machine Economy

## 1. Vision du Projet
Un SDK unifiant DePIN (Infrastructure Physique Décentralisée) et Agents IA, utilisant la blockchain Arc et le stablecoin USDC.
L'objectif est de créer une interface "Mission Control" qui sert à la fois de vitrine institutionnelle et d'outil de pilotage opérationnel pour une flotte de machines autonomes.

## 2. Identité Visuelle (Design System)
### Philosophie
"Calm Tech" 2026. Institutionnel, futuriste mais sobre. L'interface doit inspirer confiance, sécurité et haute technologie sans être "gamifiée".

### Mode
**Dark Mode First (Strict)**. Pas de fonds blancs.

### Palette de Couleurs
- **Fonds (Abyss Dark)** : `Slate-900` (#0f172a) ou `Zinc-950` (#09090b).
- **Accents Financiers (USDC Blue)** : Bleu électrique/Cyan (#2775CA ou équivalent #00E3FF pour le mode néon).
- **Statuts Opérationnels (Neon Mint)** : Vert menthe fluo (#00FFA3) pour l'activité des agents et les succès.
- **Alertes/Inactif** : Rouge/Orange néon pour les nœuds déconnectés.

### Typographie
- **Titres** : Inter ou Space Grotesk.
- **Corps** : Inter.
- **Logs/Data** : JetBrains Mono.

## 3. Tech Stack
- **Framework** : Next.js 14+ (App Router)
- **Langage** : TypeScript
- **Styling** : Tailwind CSS
- **Animations** : Framer Motion
- **3D** : Spline (@splinetool/react-spline)
- **Icônes** : Lucide React
